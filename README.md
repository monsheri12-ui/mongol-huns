# Захиалга бэлэн үү? — версия 1.8.6

Учебный продуктовый магазин на монгольском. В настройках и на заставке можно выбрать русский интерфейс. Тогда список заказа и отделы получают русские подсказки; названия продуктов, сообщения клиентов, аудио и письменный ответ на весах сохраняют монгольский учебный материал.

После получения заказа сборщик берёт пакеты, подписывает номер и имя клиента, выбирает корзину (до 6 упаковок) или тележку. Фрукты и овощи россыпью проверяются по внешнему виду. У упаковок, сеток и лотков конфет даты открываются кнопкой проверки срока. На электронных весах показываются килограммы, ответ записывается словами на монгольском; доступны подсказка, добавление, снятие лишнего и повторное взвешивание.

Проверка комплектности не раскрывает непроверенную просрочку. После доставки такого товара приходит игровое SMS с выбором свежей замены или возврата стоимости только проблемного количества. Жалоба, замена и возврат сохраняются в профиле браузера. Деньги и сообщения существуют внутри игры.

200 аудиофайлов Chimege и исходные заказы сохранены без изменения. Проверки сверяют подписи, текст, количество, голоса и SHA-256 файлов с акустическим аудитом. Новые партии добавлены без изменения старых идентификаторов сохранённых корзин.

Разработка: `npm install`, `npm run build`, `npm test`, `npm run check:release`. Раздавайте `dist/` обычным HTTP сервером. Three.js собирается из `src/store-world.js`; интерфейс и чистая логика находятся в `dist/`. Публичная версия: https://monsheri12-ui.github.io/mongol-huns/. Код для Tilda находится в `embed/tilda.html`. GitHub Pages публикует `dist/` через `.github/workflows/pages.yml`.

Новые изображения: `dist/assets/produce/produce-atlas.png`; источник, точный промпт и сетка спрайтов — в `dist/assets/produce/provenance.json`. Существующие фотографии и аудио имеют отдельные файлы происхождения и проверки.
